Engine Methodology

This document details the analytical framework underpinning the Myntra Wishlist-to-Purchase Discovery Engine. It outlines the scope of data analyzed, the specific mathematical models used to evaluate trend velocity, and the necessary caveats when interpreting the dashboard metrics.

Ranking Score Formula

The core of the Discovery Engine is the 'Intent Velocity Score' (IVS). This metric aims to surface items that are rapidly moving from casual consideration (Wishlist) to active acquisition (Cart/Purchase), prioritizing recent momentum over historical bulk volume.

Formula / Algorithm
IVS = ( W_velocity * 0.4 ) + ( C_conversion_rate * 0.6 ) * Decay_Factor // Where: W_velocity = (Current_Week_Wishlists - Prev_Week_Wishlists) / Prev_Week_Wishlists C_conversion_rate = Items_Moved_To_Cart / Total_Wishlisted_Items Decay_Factor = e^(-λt) /* Penalizes older trends */

By weighting Cart Conversion higher than raw Wishlist Velocity, the engine filters out aspirational "window shopping" trends and focuses on actionable consumer intent.

Caveats & Limitations

Users of this dashboard should be aware of the following limitations when interpreting trend data:

  • Sale Event Distortion: Major promotional events (e.g., EORS) artificially inflate 'Wishlist' velocity as users pre-load carts. The algorithm applies a smoothing function during these periods, but short-term anomalies may remain.
  • Stock-Out Censoring: High-demand items that rapidly stock out will show a sudden drop in Cart Conversion. The current model does not fully adjust for unfulfillable intent.
  • Micro-Trend Latency: Hyper-niche trends with very low initial volume may take up to 72 hours to breach the statistical significance threshold required for dashboard rendering.
